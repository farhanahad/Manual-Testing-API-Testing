#Manual Testing & API Testing

##Dynamic Search Feature Testing for E-Commerce Platform (Evershop)

###The project focused on designing, testing, and analyzing a dynamic search feature for a shoe-selling e-commerce platform built using the Evershop framework. The goal was to ensure that the search functionality works dynamically for any keyword or specific text, and that the end-to-end user journey — from searching to adding products to the cart — functions seamlessly through both UI and API testing.

###Website Link: https://demo.evershop.io/
